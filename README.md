### 🌱 关于我

我是 Violet，有会计学背景，曾在金蝶参与企业软件实施与应用支持。做过财务共享、数据治理、系统上线和驻场交付，也因此对“一个工具怎样才能真的帮到使用者”格外感兴趣。

现在，我在探索 **AI Agent、企业工作流和交互产品**。我会和 Codex、Claude Code 等 Coding Agent 协作，把想法做成原型，再通过测试和反馈不断改进。

- **业务与交付**：需求澄清、ERP 流程、SQL 数据处理、UAT 与使用文档。
- **AI 应用实践**：知识检索、受控工具调用、人工复核与评测。
- **产品与体验**：从企业工作台到生活记录应用，关注清楚的流程，也喜欢有温度的界面。
